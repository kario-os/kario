# phone-paint 设计系统

> 产品渲染器 phone-paint 的外观定稿：四套主题的配色、字号、间距、圆角、动效和对比度规则。代码里的同一张表在 `paint/src/design.rs`，`cargo test`（`make test` 的一部分）逐行核对本文 §2–§4 的表格和代码一致，并在四套主题上检查 §5 的对比度规则；改配色、字号或间距要两边一起改。phone-gui 有它自己的样式，不受本文约束（[23](23-renderer-protocol.md) §10）。

## 1. 原则

- **平面、高对比、按网格对齐**：没有阴影和渐变（待机界面除外），层次靠底色深浅和一条细边线区分。
- **一个界面只用这里的颜色和字号**：画面上的每段文字都是 §3 的某一级，每块底色都是 §2 的某个角色；新界面先在这里找，找不到再加一行，不在代码里写数值。
- **主题只换颜色，不换布局**：四套主题共用同一套字号、间距和圆角，换主题不会让文字换行或界面跳动。
- **固定深色的画面**：来电和闹钟不随主题变（一眼就要认出来），底色是 `CALL_BG` / `ALARM_BG`，上面的字用 `ON_DARK` / `ON_DARK_DIM`。
- **照片上的字一律白色**：待机壁纸上压一层从上往下变淡的黑色（不透明度 0.57 到 0.12），状态行底板是半透明黑色。
- 单位是画布的逻辑像素：480×640 的屏、缩放 2 时是 240×320。

## 3. 字号

| 级别 | 大小 | 用途 |
|------|------|------|
| `MICRO` | 8.5 | 角标、消息的时间 |
| `CAPTION` | 9.5 | 状态栏、副标题、行尾的值、分组标题、待机的操作提示、对话框的脚注 |
| `SMALL` | 10.5 | 通知横幅、提示条、待机的信息行、`dim` 样式的段落、对话框的说明 |
| `BODY` | 11 | 正文、软键、按钮、菜单项、输入框 |
| `TITLE` | 12.5 | 标题栏、`title` 样式、待机的运营商和日期 |
| `HEADLINE` | 18 | 来电的名字、闹钟的时间 |
| `LARGE` | 22 | `big` 样式 |
| `BRAND` | 26 | 开机画面的名字 |
| `DISPLAY` | 40 | 待机的时钟；`display` 样式（计算器的结果）最大到这么大 |
| `DISPLAY_MIN` | 16 | `display` 样式最小缩到这么大，再长就截断 |

字体是 Noto Sans CJK 的常规和粗体（`Face::Sans`、`Face::Bold`），等宽内容（代码、Mermaid 图）用同一套字的等宽字形。粗体只用在标题、软键中间的确认键、按钮、角标和发件人上。

| 名字 | 值 | 用途 |
|------|------|------|
| `STATUS_H` | 16 | 状态栏高度 |
| `TITLE_H` | 22 | 标题栏高度 |

| `IME_H` | 18 | 输入法候选行高度 |
| `PAD` | 6 | 屏幕边距、卡片内边距 |

| `R_S` | 4 | 格子、输入框、候选的高亮、小块的圆角 |
| `R_M` | 6 | 行、卡片、待机信息行的圆角 |
| `R_L` | 8 | 气泡、浮层、对话框的圆角 |

胶囊形（角标、提示条、一排按钮、进度条）的圆角是自己高度的一半。

## 5. 对比度规则

按 WCAG 2 的对比度算，`design.rs` 的测试在四套主题上都检查：

| 文字 | 底 | 至少 |
|------|------|------|
| `fg` | `bg` | 7:1 |
| `fg` | `bar`、`title`、`focus`、`card`、`sheet`、`bub_in`、`bub_out` | 4.5:1 |
| `dim` | `bg`、`card`、`sheet` | 4.5:1 |
| `accent`、`ok`、`warn`、`danger`、`trust`（只用于粗体字、图形和色块） | `bg` | 3:1 |
| `bg`（选中候选上的字） | `accent` | 3:1 |
| `ON_DARK` / `ON_DARK_DIM` | `CALL_BG`、`ALARM_BG` | 7:1 / 4.5:1 |

这一版定稿时调过两处：浅色和复古绿的 `dim` 原来只有 4.4:1 和 3.5:1，加深到 4.5:1 以上；聊天气泡、选项菜单、命令面板、对话框、通知横幅原来是写死的深色，浅色和复古绿主题下深色字压在深底上看不清，现在都取主题的 `bub_in` / `bub_out` / `sheet`。

## 6. 评审

- 截图：`make pixel-selftest` 把自测的每一步画成 PNG（`build/pixel/<形态>/`），`make skins` 另存一张放进机身的（`build/skins/<形态>/`），评审外观看这些。
- 大字号：「设置 › 大字号」打开后，帧带 `zoom: 1.2`，phone-paint 用 1.2 倍的缩放比例画整帧，字、行高、边距、状态栏和底栏一起放大，比例和换行规则不变，屏上的行少一些；排版回报跟着变，Shell 的滚动和可见范围随之调整（像手机「显示大小」的做法，而不是单独放大字号再挤进原来的行高）。用例「大字号」截设置首页和待机界面（`91-large-text-*.png`）。文本界面的字符格不变；phone-gui 只用来对照，不处理 `zoom`。
- 四套主题：自测在默认主题下截图；用例「四套主题的截图」在设置里依次换成浅色、复古绿、琥珀、深色，每套截待机界面、主菜单、设置首页（`90-theme-<主题>-<界面>.png`）。
